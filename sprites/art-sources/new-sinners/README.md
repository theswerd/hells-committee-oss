# New sinner illustrations

Each WebP sheet contains one original character in two poses: idle on the left and shocked on the right. The sheets were created for Hell’s Committee with OpenAI image generation and retain transparency. Run `npm run sprites:sinners` to crop and package the 42 game-ready sprites in `public/art/`.

When adding a new sinner, draw a new character with their own face, silhouette, clothes, and props. Keep their details consistent between the two poses; do not recolor another person.
